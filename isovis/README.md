# IsoVis

Published at https://csp256.github.io/isovis/ from
[the IsoVis source repository](https://gitlab.com/csp256/isovis), revision
`8f25a7793b6f5719bfb94e8cd88f2cc874f2794f`. The app and all its libraries are served locally from this folder;
upstream library licenses/notices are retained.

The original `isovis.html` entry point is named `index.html` here so the app opens
at the folder URL. `/isovis.html` at the site root redirects here, preserving URL
parameters and shared-session fragments. `fitness/` is independent and unchanged.

For development, tests and updates, use the source repository. To refresh this
static snapshot, copy its `isovis/` contents into this folder, rename the copied
`isovis.html` to `index.html`, and update the revision above. Keep this README and
the root redirect. No compilation is needed to publish committed browser files.
